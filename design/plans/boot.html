BIOS Launcher · Design note

Boot Splash

A PlayStation 2–style boot screen shown on index.html while the orrery’s WebGPU shaders compile — drifting cubes in a blue nebula, three colored light trails, the wordmark. It never rests: on exit the wordmark fades, the camera flies into the fog past the cubes, and the trails morph to the orrery’s node positions.

Constraints

Why lightweight

The splash exists to cover the moment the orrery’s shaders compile. So it can’t itself depend on shader compilation, or it needs its own splash. Everything below is CSS plus a 2D <canvas> — it paints on the first frame, before any WebGPU work starts.

Splash Sequence

The splash markup sits first in <body>, so it covers everything from the first paint. The orrery renders live behind the splash the whole time. The wordmark is a self-contained beat near the middle; the exit is a separate later beat that splash.js holds back until both orrery:ready has fired and at least 3 s have passed since splash start. Exit steps 4–5 start together.

  1. 1Wordmark fades in. Almost immediately — first frame, ~200 ms (.splash--lit).
  2. 2Wordmark holds ~1 s, then fades out over ~1.5 s (.splash--dim, added ~1 s in) — gone by ~2.5 s, well before the exit. It takes no part in .splash--out.
  3. 3Gate. Once orrery:ready and the 3 s floor are both met, the exit begins (.splash--out).
  4. 4Camera flies into the fog — 0.75 s. The fog scales up hard toward the viewer; the cubes blow past outward.
  5. 5Trails morph to the orrery — 0.75 s. Starts with step 4. Each of the three trails eases from its live position to one of the orrery’s node initial positions, which splash.js computes from the orrery layout at that instant (time-based: the 8 nodes sit on the tilted orbit rotated by the current spin). Drawn additively.
  6. 6Splash exits. The .splash layer fades over ~1.5 s; on transitionend it gets hidden and the canvas loop stops — the orrery, already spinning, is all that’s left.
  7. Failsafe: Hard timeout (7s) starts the choreography even if orrery:ready never arrives. The splash can never get stuck.

Components

Fog

CSS · layered radial-gradients + SVG feTurbulence

Irregular blue gradient blobs over black with slow drift keyframes, warped by an animated feDisplacementMap, with a second wispy feTurbulence cloud multiplied into the fog (dark surround stays dark) and screened back as highlights — so it roils instead of reading as banded CSS. No canvas, no shader.

Cubes

2D canvas · ~7 instances

Dark isometric hex outlines with faint face shading, drifting across with per-cube tumble and depth — size, opacity and blur keyed to a z value, edge-wrapping. Canonically the “memories” from save data; here just a fixed count.

Light trails

2D canvas · same context as cubes

Three comet streaks — red, green, violet, matched to the reference frame — firing across on a stagger with fading tails, then respawning after a delay. On exit each eases over ~0.75 s to one of the orrery’s node initial positions — computed from the orrery layout at that instant, so it’s time-based — drawn additively.

Wordmark

CSS text · in on the first frame, out ~1–2.5 s in

“Coldstart Computer Entertainment” in plain letter-spaced type with a soft blue glow — the way the console drew its full maker name, not a logo lockup. A self-contained mid-sequence beat: in, a ~1 s hold, then a ~1.5 s fade-out — done before the exit and no part of it. coldstart is the term for a boot from fully powered-off state, no cached anything — which is what this screen is.
