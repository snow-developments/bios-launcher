# BIOS Launcher Design References

These references inform the launcher’s atmospheric startup language: a dark blue
field, floating geometry, restrained typography, a slow orbital motion, and a
clock/system-status focal point. They are inspiration and technical reference,
not copied assets or code.

## References

- [RetroReversing — PlayStation 2 reverse engineering](https://www.retroreversing.com/ps2)\
  Hardware, graphics, and software context for the PS2 platform.
- [Rodrigo Copetti — PlayStation 2 Architecture](https://www.copetti.org/writings/consoles/playstation-2)\
  Technical analysis of the Emotion Engine, graphics system, and console
  architecture.
- [All PS2 BIOS — PS2 startup sound](https://allps2bios.com/ps2-startup-sound/)\
  Describes the startup mood: dark screen, blue logo, floating blocks, and
  cinematic audio.
- [Babyno — Parsing the PS2 3D icon](https://babyno.top/en/posts/2023/10/parsing-ps2-3d-icon/)\
  Technical reference for animated 3D icons, orbital presentation, lighting,
  textures, and background color.
