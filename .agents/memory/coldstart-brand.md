The boot splash shows the maker mark **Coldstart Computer Entertainment** (DBA
**Coldstart**) — an homage to the PS2's "Sony Computer Entertainment" boot
text. "Coldstart" is the term for booting from a fully powered-off state with
nothing cached, which is what the screen depicts.

Corporate framing (fictional, for the homage): Coldstart is a wholly owned
subsidiary operated by **Snow Developments, LLC** — the real studio name, which
belongs on `about.html`, not the splash.
